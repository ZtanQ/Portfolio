Project screenshots and generated charts go here.

Reference them from `src/data/projects.ts`:

```ts
image: {
  src: "/projects/aldimi-dashboard.png",
  alt: "ALDIMI Predict dashboard showing clinical risk distribution",
},
```

Guidance:
- 4:3 aspect ratio, at least 1024px wide.
- Alt text describes what the image shows, not "screenshot of X".
- A project without an image renders in typographic mode — that's fine,
  don't add a weak screenshot just to fill the slot.
